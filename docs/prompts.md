## Запрос 1 — структура и весь сайт

**Текст запроса:**

> создай мне сайт по данному промту все требование находиться в файле

К запросу приложен файл технического задания `TZ-20_Klining_Chistyy_List.pdf` (ТЗ № ТЗ-20/2026).

**Что получилось:**

- 10 страниц на обычном HTML без сборки: index, services, calculator, subscription, office, tips, contacts, thanks, privacy, 404; единые шапка и подвал, выделение текущего пункта меню, `<title>`, description и Open Graph на каждой странице, favicon.
- `css/style.css` — фирменные цвета и шрифты Montserrat/Inter, адаптивная вёрстка для 375 / 768 / 1280 px.
- `js/analytics.js` — все вызовы `gtag('event', …)`, разметка через `data-event`.
- `js/main.js` — меню, сохранение UTM в `sessionStorage`, галерея, промокод, расчёт экономии подписки.
- `js/calculator.js` — калькулятор по разделу 2 ТЗ (минимум 3 000 ₽, подписка, акция, большая скидка).
- `js/form.js` — выбор даты (14 дней с завтрашнего, 08:00/11:00/14:00/17:00), проверка полей, отправка `fetch`, `form_error`, `generate_lead`, страница «Спасибо».
- `apps-script/Code.gs` — приёмник заявок `doPost(e)` с проверками и защитой от повторного `request_id`, функция `setupSheet()`.
- Картинки «до и после» (иллюстрации), OG-картинка 1200 × 630, два PDF-чек-листа, `docs/events.md`, `docs/utm.csv`.

**Что пришлось исправить вручную:**

- _заполнить после проверки: например, вставить свой идентификатор G-…, URL Apps Script, ссылки на соцсети_
