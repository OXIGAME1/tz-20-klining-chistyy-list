## Состав

- 9 страниц + `404.html` — обычный HTML/CSS/JS, открываются без сборки.
- `js/analytics.js` — все события GA4 (таблица — `docs/events.md`).
- `js/main.js` — меню, UTM-метки в `sessionStorage`, галерея, промокод, подписка.
- `js/calculator.js` — калькулятор стоимости.
- `js/form.js` — выбор даты, форма заказа, страница «Спасибо».
- `apps-script/Code.gs` — приёмник заявок для Google Таблицы.
- `docs/` — журнал запросов, события, реестр UTM, источники картинок, аналитическая записка.

## Настройка перед публикацией

1. **GA4.** Тег `G-TCNW88BN83` уже стоит во всех `*.html`. Для DebugView откройте сайт с `?debug_mode=1`.
2. **Таблица и приёмник.** Создайте таблицу «ChistyList — Orders» → Расширения → Apps Script → вставьте `apps-script/Code.gs`, впишите `SHEET_ID`, запустите `setupSheet`, разверните как веб-приложение (доступ — все). URL `…/exec` вставьте в `APPS_SCRIPT_URL` в `js/form.js`.
3. **Соцсети.** Ссылку на Instagram в подвале и на `thanks.html` замените на профиль, созданный для проекта.
4. **Адрес сайта.** Если Vercel выдал другой адрес — замените `tz-20-klining-chistyy-list.vercel.app` в `<head>` страниц, `robots.txt`, `sitemap.xml` и `docs/utm.csv`.

## Объём работ по каналам

По решению преподавателя размещение ссылок выполняется только в Instagram: строки реестра U-01…U-04. ВКонтакте, Telegram, YouTube, блогеры и QR-код на магните (U-05…U-12) из задания исключены, поэтому короткие ссылки, `docs/qr-u-12.png` и `docs/afisha.pdf` не создаются.

## Решения по калькулятору

- Скидки применяются ко всему заказу (уборка + доп. услуги); акция и подписка не суммируются — берётся большая.
- Акция «−15 % на генеральную» включается автоматически с 15.11 по 15.12.2026 или по промокоду CLEAN15.
- Подписка доступна только для поддерживающей уборки.
- Поле «Адрес уборки» необязательное и пишется в дополнительный последний столбец `address` таблицы.
